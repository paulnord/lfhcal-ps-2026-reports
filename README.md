# LFHCal PS-2026 calibration reports

Web reports for the April 2026 CERN PS LFHCal data, generated at BNL.

The current report uses Legacy HG fitting with the original fit boundary.

Open `index.html` on the GitHub Pages site to browse sets, calibration stages,
and the original plots. Individual summary PDFs are included with the report.

The combined `ps-2026-r5-report.pdf` and ZIP bundles are intentionally excluded
from this repository. The full report is available in the
[BNLBox report folder](https://bnlbox.sdcc.bnl.gov/index.php/s/easGNXHQc8xAYCY).
[Individual summary PDFs on BNLBox](https://bnlbox.sdcc.bnl.gov/index.php/s/ngokWngJJXzMzm8)
are also available.

Published files are assembled from existing analysis output; publishing does not
rerun calibration or alter any plot data. Run associations and provenance are
recorded in `manifest.json` and the CSV inventories accompanying the report.

GitHub Pages is configured to publish the root of the `main` branch.
